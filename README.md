## 如何安装

这里的插件都是**免打包的浏览器扩展**，不需要上架商店，直接用浏览器的「加载已解压的扩展程序」就能装。

### 第一步：把插件下载到本地

- **下载全部**：点本仓库右上角绿色的 **Code → Download ZIP**，下载后解压到任意目录
- **只下载某一个**：进入对应插件目录，单独下载该目录即可

### 第二步：在浏览器里加载

以 Chrome 为例（Edge 操作完全相同，只是地址换成 `edge://extensions/`）：

1. 地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 在弹出的选择框里，选中**插件所在的文件夹本身**（例如 `batch-webpage-opener`），点「选择文件夹」

> ⚠️ **关键一步**：选的是**文件夹**，不要进到文件夹里面去选某个文件（比如 `manifest.json`）。
> 选错层级会报「清单文件缺失或不可读取」。

5. 加载成功后，扩展会出现在列表里。点浏览器工具栏的拼图图标 → 找到它 → 点「固定」，就能在工具栏上直接用了

### 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 提示「清单文件缺失或不可读取」 | 选错层级了，重新选到**插件文件夹本身** |
| 想更新到新版本 | 重新下载覆盖原文件夹，回到 `chrome://extensions/` 点该扩展卡片上的**刷新**按钮 |
| **删掉/移动了插件文件夹后，扩展失效了** | 「加载已解压的扩展程序」是**引用式**安装，浏览器直接从这个文件夹读文件。文件夹被删或移走，扩展就失效。把文件夹放回**原路径**后点「刷新」即可恢复；路径变了则重新加载一次 |
| 想删掉插件文件夹 | **先去 `chrome://extensions/` 把该扩展「移除」，再删文件夹**，否则扩展会一直报错 |
| 不想用了 | 在扩展卡片上点 **移除** |

> 建议把插件文件夹放在一个**固定位置**（例如 `文档/extensions/`），不要放桌面——桌面容易被顺手清理，一删扩展就失效。

## 目录约定

```
hqf-extensions/
├── batch-webpage-opener/      # 一个插件一个目录
├── <next-plugin>/
└── README.md
```

- 每个插件目录自带 `README.md`，写清功能、目录结构、安装方式
- 只提交源码，构建产物（`node_modules/`、`dist/`、`build/`）不纳入版本管理
